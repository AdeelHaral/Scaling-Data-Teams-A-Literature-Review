# Scaling-Data-Teams-A-Literature-Review

Scaling Data Teams: A Literature Review. A structured review of research, industry literature, frameworks, and case studies on building and scaling effective data teams.

## Project workflow

1. Phase 1: Deep research
2. Phase 2: Audit the research and identify the strongest evidence and arguments
3. Phase 3: Build the intellectual storyline for the 90-minute class
4. Phase 4: Divide it into three 30-minute sections
5. Phase 5: Build slides, diagrams, and case studies
6. Phase 6: Build speaker notes and transitions
7. Phase 7: Prepare professor-style Q&A
